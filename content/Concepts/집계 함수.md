# 집계 함수

## 한 줄 정의

여러 행을 입력받아 그룹당 하나의 결과를 반환하는 다중행 함수(SUM/AVG/MAX/MIN/COUNT)다.

## 핵심 규칙

- SUM/AVG/MAX/MIN은 모두 [[NULL]]을 제외하고 계산한다.
- [[COUNT]](*)는 NULL을 포함해 모든 행을 세지만, COUNT(열)은 NULL인 행을 제외한다.
- AVG는 NULL을 분자뿐 아니라 분모(나누는 행 수)에서도 제외한다.
- [[GROUP BY]] 없이 집계 함수를 쓰면 테이블 전체를 하나의 그룹으로 간주한다.
- [[WHERE]]절에서는 집계 함수를 조건으로 사용할 수 없고, [[HAVING]]에서만 가능하다.
- 공집합일 때 COUNT는 0을 반환하지만 나머지 집계 함수는 NULL을 반환한다.

## 판단 순서

1. GROUP BY 유무를 먼저 확인해 그룹 단위를 파악한다.
2. 대상 데이터에 NULL이 있는지 확인한다.
3. 어떤 집계 함수인지에 따라 NULL 포함/제외 규칙을 적용한다.
4. WHERE와 HAVING 중 어디에 조건이 걸려 있는지 확인해 집계 함수 사용 가능 여부를 판단한다.

## 자주 혼동하는 개념

| 비교 대상                       | 차이                                                          |
| --------------------------- | ----------------------------------------------------------- |
| COUNT(*) vs COUNT(열)        | NULL 포함 여부가 다름                                              |
| SUM/AVG/MAX/MIN vs COUNT(*) | 전자는 NULL 제외, COUNT(*)만 NULL 포함                              |
| WHERE vs HAVING             | WHERE는 집계 함수 조건 불가, HAVING은 가능                              |
| AVG vs SUM/COUNT 조합         | AVG는 자체적으로 NULL을 분모에서도 제외하므로 SUM/COUNT(*)로 직접 나눈 값과 다를 수 있음 |

## 대표 함정

- NULL이 하나라도 있으면 SUM 전체가 무효화(NULL 또는 0)된다고 오해(M01-Q11, M01-Q38, M01-Q49).
- WHERE절에 집계 함수 조건을 그대로 써서 오류가 나는 이유를 GROUP BY나 SUM 문법 탓으로 오판(M01-Q20).
- AVG가 COUNT(*)와 같은 분모를 쓴다고 착각(M01-Q29).

## 능동 회상

### 1. GROUP BY 없이 SUM을 쓰면 테이블을 어떤 단위로 취급하는가?

> [!success]- 답 확인
> 테이블 전체를 하나의 그룹으로 취급한다.

### 2. COUNT(*), COUNT(열), SUM, AVG 중 NULL을 포함하는 것은 무엇인가?

> [!success]- 답 확인
> COUNT(*)만 NULL을 포함한다.

### 3. 집계 함수 조건은 왜 WHERE절에 쓸 수 없는가?

> [!success]- 답 확인
> WHERE는 GROUP BY(집계) 이전에 실행되어 아직 집계 결과가 존재하지 않기 때문이다.

### 4. AVG(컬럼)의 분모는 전체 행 수인가, NULL 제외 행 수인가?

> [!success]- 답 확인
> NULL 제외 행 수다.

### 5. 공집합일 때 COUNT와 나머지 집계 함수의 반환값은 각각 무엇인가?

> [!success]- 답 확인
> COUNT는 0, 나머지는 NULL을 반환한다.

## 관련 개념

- [[GROUP BY]]는 집계 함수의 계산 단위(그룹)를 결정한다.
- [[HAVING]]은 집계 함수 결과를 조건으로 걸 수 있지만 [[WHERE]]는 그럴 수 없다.
- [[COUNT]]는 다른 집계 함수와 달리 대상 표기(*, 열)에 따라 NULL 처리 방식이 갈린다.
- [[NULL]]은 집계 함수 대부분에서 제외되지만 COUNT(*)에서는 포함된다.
