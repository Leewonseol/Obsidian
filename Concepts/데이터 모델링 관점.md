# 데이터 모델링 관점

## 한 줄 정의

데이터 모델링은 데이터 관점, 프로세스 관점, 상관 관점(CRUD) 3가지로 업무를 분석한다.

## 핵심 규칙

- 데이터 관점(What): 업무가 어떤 데이터와 관련되는가
- 프로세스 관점(How): 업무가 어떤 흐름·절차로 수행되는가
- 상관 관점(CRUD): 업무 흐름에 따라 데이터가 생성·조회·수정·삭제되는가
- "정규화 관점"은 원본에 존재하지 않는 개념이며 시험에서 오답 함정으로 자주 활용된다.

## 능동 회상

### 1. 데이터 모델링의 3가지 관점은 무엇인가?

> [!success]- 답 확인
> 데이터 관점, 프로세스 관점, 상관 관점(CRUD).

### 2. "정규화 관점"은 실제로 존재하는 관점인가?

> [!success]- 답 확인
> 존재하지 않는다(원본에 없는 오답 함정 개념).
