# 윈도우 함수

## 한 줄 정의

OVER절과 함께 사용되어 행 그룹(윈도우) 내에서 순위·누적값 등을 계산하는 함수군이다. 원본 마인드맵에는 없어 PDF 해설로 보강되었다.

## 핵심 규칙

- RANK(): 동일 값에 동일 순위, 다음 순위는 동점 개수만큼 건너뜀.
- DENSE_RANK(): 동일 값에 동일 순위, 다음 순위는 건너뛰지 않음.
- ROW_NUMBER(): 동일 값이라도 고유 순번 부여.
- ROWS BETWEEN n PRECEDING AND m FOLLOWING: 지정한 물리적 행 범위로 이동 집계.
- TOP(n) WITH TIES(SQL Server): 상위 n개와 동점인 행 모두 포함.
- RATIO_TO_REPORT(value) OVER (PARTITION BY ...): Oracle 함수로, 파티션 합계에 대한 현재 행 값의 비율을 반환한다. 순위 함수가 아니라 비율 함수이며, 표준 SQL로는 `value / SUM(value) OVER (PARTITION BY ...)`로 동일하게 표현할 수 있다.
- FIRST_VALUE(expr) OVER (...): 지정한 윈도우 프레임 안에서 첫 번째 값을 반환한다. ORDER BY만 보고 전체 파티션의 첫 값이라 단정하면 안 되며, 프레임(ROWS/RANGE) 범위에 따라 "첫 번째"의 기준이 달라진다.

## ROWS와 RANGE

- ROWS: 실제 행의 물리적 위치를 기준으로 프레임을 구성한다(예: ROWS BETWEEN 1 PRECEDING AND CURRENT ROW는 바로 앞 1행과 현재 행).
- RANGE: ORDER BY 값이 동일한 동료(peer) 행을 모두 같은 프레임에 포함할 수 있다(예: RANGE UNBOUNDED PRECEDING은 시작부터 현재 행과 같은 정렬값을 가진 모든 행까지 포함).
- ORDER BY 값이 여러 행에서 동일하면, ROWS 프레임은 물리적 행 수만큼만 누적하지만 RANGE 프레임은 동일 값 행을 한꺼번에 포함하므로 누적합 결과가 서로 달라질 수 있다.

## 판단 순서

1. RANK/DENSE_RANK/ROW_NUMBER 중 무엇인지 확인한다.
2. 동점 값이 있는지 확인하고, 순위 처리 방식을 적용한다.
3. ROWS BETWEEN이 있다면 각 행별 물리적 범위를 개별 계산한다.
4. 프레임이 ROWS인지 RANGE인지 확인하고, RANGE라면 동일 정렬값 동료 행이 함께 포함되는지 점검한다.
5. RATIO_TO_REPORT·FIRST_VALUE처럼 순위 계산이 아닌 함수는 무엇을 반환하는지(비율인지, 프레임 내 특정 위치 값인지) 먼저 구분한다.

## 자주 혼동하는 개념

| 비교 대상 | 차이 |
|---|---|
| RANK vs DENSE_RANK | RANK는 다음 순위를 건너뜀, DENSE_RANK는 안 건너뜀 |
| RANK vs ROW_NUMBER | ROW_NUMBER는 동점도 고유 순번 |
| RATIO_TO_REPORT vs RANK 계열 | RATIO_TO_REPORT는 순위가 아니라 파티션 합계 대비 비율을 반환 |
| ROWS vs RANGE | ROWS는 물리적 행 위치 기준, RANGE는 ORDER BY 동일 값(동료 행)까지 포함 |

## 대표 함정

- DENSE_RANK를 RANK나 ROW_NUMBER 방식과 혼동(M01-Q23).
- TOP(n) WITH TIES에서 동점 행을 누락(M01-Q24).
- ROWS BETWEEN에서 FOLLOWING(뒤쪽 범위)을 빠뜨림(M01-Q35).
- RATIO_TO_REPORT를 순위 함수로 착각하거나, FIRST_VALUE가 프레임과 무관하게 항상 파티션 전체의 첫 값을 반환한다고 착각.
- RANGE 프레임에서 ORDER BY 값이 같은 행들이 함께 누적된다는 점을 놓치고 ROWS와 동일하게 계산.

## 능동 회상

### 1. DENSE_RANK는 동일 값 다음 순위를 건너뛰는가?

> [!success]- 답 확인
> 건너뛰지 않는다.

### 2. TOP(2) WITH TIES는 몇 개 행을 반환할 수 있는가?

> [!success]- 답 확인
> 2개 이상(2위와 동점인 행까지 포함).

### 3. RATIO_TO_REPORT는 순위를 반환하는가?

> [!success]- 답 확인
> 아니다. 파티션 합계에 대한 현재 행 값의 비율을 반환하는 Oracle 함수다.

### 4. ROWS 프레임과 RANGE 프레임의 핵심 차이는 무엇인가?

> [!success]- 답 확인
> ROWS는 물리적 행 위치를 기준으로 하고, RANGE는 ORDER BY 값이 같은 동료 행까지 함께 포함할 수 있다.
