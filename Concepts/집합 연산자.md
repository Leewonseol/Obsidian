# 집합 연산자

## 한 줄 정의

두 개 이상의 SELECT 결과를 합집합·교집합·차집합 방식으로 결합하는 연산자(UNION/UNION ALL/INTERSECT/MINUS)다.

## 핵심 규칙

- UNION: 두 결과의 합집합(중복 제거)
- UNION ALL: 두 결과의 합집합(중복 유지)
- INTERSECT: 두 결과의 교집합(중복 제거)
- MINUS: 첫 번째 결과에서 두 번째 결과를 뺀 차집합(중복 제거), Oracle의 명칭이다.
- EXCEPT: MINUS와 동일한 차집합 연산이며, 표준 SQL과 SQL Server 등에서 쓰는 명칭이다(Oracle은 MINUS만 지원).
- 두 SELECT의 열 개수와 대응하는 자료형이 서로 호환되어야 한다.
- 최종 ORDER BY는 개별 SELECT가 아니라 집합 연산 전체 결과에 한 번만 적용한다.
- UNION ALL을 제외한 나머지(UNION/INTERSECT/MINUS/EXCEPT)는 모두 결과에서 중복을 제거한다.

## DBMS별 차집합 명칭

| 연산자 | 주 사용 DBMS |
|---|---|
| MINUS | Oracle |
| EXCEPT | 표준 SQL, SQL Server, DuckDB 등 |

- 두 연산자는 같은 차집합 의미를 가지며, 문제의 전제 DBMS에 따라 명칭만 다르다는 점을 확인해야 한다.

## 능동 회상

### 1. UNION과 UNION ALL의 차이는 무엇인가?

> [!success]- 답 확인
> UNION은 중복을 제거한 합집합, UNION ALL은 중복을 유지한 합집합이다.

### 2. MINUS 연산자는 무엇을 반환하는가?

> [!success]- 답 확인
> 첫 번째 결과에서 두 번째 결과를 뺀 차집합.

### 3. EXCEPT와 MINUS는 같은 연산인가?

> [!success]- 답 확인
> 같다. EXCEPT는 표준 SQL·SQL Server 등에서 쓰는 이름이고, MINUS는 Oracle에서 쓰는 이름일 뿐이다.
