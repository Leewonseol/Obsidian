# 유선배 1회 확정 규칙 최소 보강

## 작업 원칙

- 완전 누락된 LIKE만 새 Concept로 생성
- 기존 Concept가 있는 항목은 세부 규칙만 보강
- Question·Proposition·구조축은 수정하지 않음
- 나머지는 두 번째 문제집까지 보류

## 신규 Concept

- [[LIKE]] — 정의·와일드카드(`%`/`_`)·ESCAPE·NULL과의 상호작용·NOT LIKE 함정을 다루는 조건 연산자 Concept 신설(대응 Concept 완전 부재, PDF Q38 근거)

## 보강한 기존 Concept

| Concept | 추가한 규칙 | 근거 |
|---|---|---|
| [[NULL]] | NVL·COALESCE·NULLIF·IFNULL·ISNULL 함수별 인수 개수·동작 표, NULLIF의 자료형 불일치 오류 가능성, `분자/NULLIF(분모,0)` 0나누기 방지 패턴, LIKE와의 상호작용 링크 | PDF Q12, Q33 |
| [[계층형 질의]] | LEVEL·CONNECT_BY_ROOT·CONNECT_BY_ISLEAF·CONNECT_BY_ISCYCLE·SYS_CONNECT_BY_PATH·NOCYCLE 6개 내장함수, PRIOR 방향(정방향/역방향) 구분, SELF JOIN과의 관계(대체 가능 범위) | PDF Q11, Q20, Q31, Q41 |
| [[윈도우 함수]] | RATIO_TO_REPORT(비율 함수, 순위 아님), FIRST_VALUE(프레임 의존성), ROWS vs RANGE(동일 정렬값 동료 행 포함 여부) | PDF Q19, Q21 |
| [[집합 연산자]] | EXCEPT(표준 SQL·SQL Server 명칭)와 MINUS(Oracle 명칭)가 동일 차집합 연산임을 명시, 열 개수·자료형 호환 요건, ORDER BY는 전체 결과에 1회 적용 | PDF Q49 |
| [[GROUP BY]] | SELECT 별칭을 GROUP BY 절에서 바로 참조할 수 없다는 규칙(Oracle 기준)과 DBMS별 허용 차이 주의, 원식 반복 예시 | PDF Q24 |

## 보류한 후보

두 번째 문제집 검증 대기 보고서 링크를 포함한다.

- [[_reports/2차-문제집-반복누락-검증대기|두 번째 문제집 반복 누락 검증 대기]]

## 구조 변경 여부

- atomic Concept 수: 54개 → 55개(LIKE 신규 1개 추가)
- structural_axis Concept 수: 변화 없음(4개)
- Question 수: 변화 없음(50개)
- Proposition 수: 변화 없음(200개)
- graph.json: 변화 없음
- 중심성 재계산: 없음

## 예상 효과

- LIKE·ESCAPE 판별 가능(이전에는 대응 Concept 자체가 없었음)
- NULL 처리 함수 4~5종의 인수 개수·반환값 차이 판별 가능
- 계층형 질의의 PRIOR 방향과 내장함수 목록 판별 가능
- 윈도우 프레임(ROWS/RANGE) 차이와 RATIO_TO_REPORT·FIRST_VALUE 구분 가능
- EXCEPT와 MINUS가 같은 연산의 다른 이름임을 판별 가능
- GROUP BY 별칭 참조 제한 판별 가능

이번 보강은 유선배 모의고사 1회 한 회에서 확인된 규칙만 반영한 것이며, 나머지 후보의 구조 변경 필요 여부는 두 번째 문제집 확인 후 판단한다.
