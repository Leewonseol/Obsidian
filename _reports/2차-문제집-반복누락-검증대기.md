# 두 번째 문제집 반복 누락 검증 대기

## 목적

유선배 모의고사 1회에서 발견된 누락과 저표현이 다른 문제집에서도 반복되는지 확인한 뒤 Concept·Proposition·링크 구조 변경 여부를 결정한다.

## 이번에 즉시 반영한 항목

| 항목 | 반영 방식 | 반영 이유 |
|---|---|---|
| LIKE·ESCAPE | 새 Concept | 독립 규칙군이 완전히 누락됨 |
| NULL 함수 | 기존 NULL 보강 | NULL Concept는 있으나 함수별 규칙 부족 |
| 계층형 질의 | 기존 Concept 보강 | PRIOR·내장 기능·SELF JOIN 관계 부족 |
| 윈도우 함수 | 기존 Concept 보강 | 일부 직접 출제 함수와 프레임 규칙 부족 |
| 집합 연산자 | 기존 Concept 보강 | EXCEPT·MINUS 차이 부족 |
| GROUP BY | 기존 Concept 보강 | 별칭과 실행순서 규칙 부족 |

## 두 번째 문제집에서 확인할 항목

| 후보 | 1차 문제집 근거 | 2차 확인 기준 | 반복 시 권장 조치 |
|---|---|---|---|
| 식별자 세부 유형 | 유선배 관련 문항(Q7) | 별도 직접 출제 여부 | 기존 Concept 보강 |
| IE 표기법 | ERD 관련 문항(Q2, Q10) | 표기법 판별 반복 여부 | ERD·관계 Concept 보강 |
| 반정규화 세부 유형 | 반정규화 문항(Q5) | 구체적 기법 반복 여부 | 기존 Concept 보강 |
| D축 소속 확대 | DBMS 차이 문항(Q24, Q41, Q49) | 동일 차이 반복 여부 | 구조축 소속 검토 |
| 계층형 질의 링크 | 다수 출제(Q11, Q20, Q31, Q41) | JOIN·재귀 관계 반복 여부 | 링크 또는 Proposition 검토 |
| 집합 연산자 링크 | 다수 출제(Q14, Q18, Q22, Q49) | NULL·중복·정렬 결합 여부 | 링크 또는 Proposition 검토 |

## 판정 기준

### 즉시 보강

다음 중 하나를 충족하면 기존 Concept 규칙을 보강한다.

- 두 번째 독립 자료에서도 같은 규칙이 직접 출제됨
- 현재 설명만으로 정답 판별이 불가능함
- SQLD의 핵심 DBMS 차이로 반복 확인됨

### 새 Concept 검토

다음을 모두 충족할 때만 새 Concept를 검토한다.

- 독립된 정의와 규칙이 있음
- 여러 Question에서 직접 출제됨
- 기존 Concept 내부에 넣으면 지나치게 혼합됨
- 독립 복습 단위로 사용할 가치가 있음

### 보류 유지

다음이면 구조 변경을 보류한다.

- 한 문제집에서만 등장
- 기존 Concept 내부 한두 문장으로 충분
- 단순 함수명 또는 문법 토큰
- 링크 수만 늘고 새로운 규칙은 추가되지 않음

## 두 번째 문제집 투입 시 기록할 값

- 자료명
- 문항 수
- 반복 출제된 누락
- 새로 발견된 누락
- 기존 보강으로 해결된 문항
- Concept 추가가 필요한 항목
- Proposition 추가가 필요한 항목
- 링크만 필요한 항목
- 변경 불필요 항목

두 번째 문제집이 아직 없으므로 현재 상태를 검증 완료로 표시하지 않는다.
